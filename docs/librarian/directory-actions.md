# 目录文件管理验收

桌面使用 Chromium 1440 × 900，触屏使用 Chromium 的 390 × 844 和 320 CSS px 模拟。测试使用隔离的 Rust 工作区、成员账号、实际文件系统和 Git 版本。改前使用 Reader 集成基线 `f16ae23b`。改后从产品提交 `4c5b5259` 构建网页与原生服务。

| 实际操作 | 观察结果 | 画面 |
| --- | --- | --- |
| 阅读「走访手记」，右键另一篇「访谈」 | 原菜单只有新建、搜索和改名，跨目录整理须在空间设置手填两条路径。改版后，菜单作用行有独立底色，阅读行保留当前标记。删除与其他操作分组。 | [改前菜单](evidence/directory-actions/before-menu.png) · [改前设置](evidence/directory-actions/before-settings.png) · [改后菜单](evidence/directory-actions/directory-menu.png) |
| 把「访谈」移到另一个空间的「归档」 | 选定位置后显示新增 1 位阅读成员。成功后正在读的文章仍在滚动位置 560 px。主动点「查看位置」才切换空间。另一个只有目标空间阅读权限的账户可用原链接打开新位置并保留片段标识。给它源空间阅读权限并收回目标权限后，原链接显示无法读取。 | [移动与权限提示](evidence/directory-actions/permission-preview.png) |
| 手机把文档复制到成员权限相同的另一个空间，再删除并撤销目标文件夹 | 目标选择器直接给出「复制到此处」。副本 ID 与原件不同。撤销恢复副本原有 ID 和目录，原件内容及位置保留。 | [手机复制](evidence/directory-actions/touch-copy.png) |
| 选择已有同名文件的目录，然后在选择器内新建子目录 | 同名提示与禁用的提交按钮同时出现。选中新建目录后，文件移动到新位置，键盘焦点落在文件行。 | [真实浏览器用例](../../apps/reader/tests/e2e/document-file-actions.spec.ts) |
| 在 320 px 触屏上，把空文件夹复制到没有文档的工作空间 | 新建的目标目录可直接选取。点「查看位置」后展开目标目录，焦点和操作标记落在新的空文件夹上。服务端目录列表包含复制出的空文件夹。 | [空文件夹位置](evidence/directory-actions/empty-folder-location.png) |

弹窗打开后，同名替换的文件夹会触发冲突，重新打开目录行可以选中新的对象。当前文档有草稿时，会先保存再预览涉及它的操作。模拟服务器已删除文件、网关返回 502 时，用相同的操作 ID 重试可以拿回回执，随后撤销会恢复带最新草稿的文档。 [浏览器回归用例](../../apps/reader/tests/e2e/document-file-actions.spec.ts)

服务端回归核对源与目标读写角色、目标撤权、成员换人、同名冲突、重复提交、二进制附件与提纲、空间隔离、删除撤销及中断重启。文档移动保留 ID，副本取得独立 ID。跨空间的当前内容按目标空间鉴权，固定快照继续读取原空间固定的版本。撤销删除后，恢复文档在删除前的版本可再次查看。[权限与目录服务测试](../../bin/librarian/tests/file_actions.rs) · [文件事务与恢复测试](../../bin/librarian/tests/workspaces/file_action_storage.rs)

单次事务沿用现有版本引擎的批量限制，文件夹中的提纲和附件也计算在内。同空间移动最多 32 个文件，其余文件操作最多 64 个文件，每批内容最多 24 MiB。超过限制时选择器提示分批整理。

使用 Node.js 24.22.1、Rust 1.99.1 和锁文件里的 Playwright Chromium。

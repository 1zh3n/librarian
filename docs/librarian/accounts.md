# 账号与工作区成员

用 `librarian init --admin-invite` 打印一次性管理员邀请；在邀请页设置自己的密码并绑定 TOTP 后，首个服务器管理员才创建。管理员登录后可从命令菜单打开「账号管理」，创建普通账号、停用或启用账号、重置密码和撤销现有会话。登录用户可从「修改密码」验证原密码并更换。新密码至少 15 个字符，且最多 4096 字节。

重置或更改密码会撤销旧会话、MCP 授权所使用的身份版本和账号 API 令牌。停用账号立即拒绝登录和访问，同时撤销该账号现有凭证。管理员单独执行「撤销会话」时，账号密码与独立 API 令牌继续有效。最后一个可用管理员保留启用状态。

工作区所有者和服务器管理员可在工作区管理页按用户名添加成员，再修改阅读或写入权限。写成员可以更改正文。阅读成员可以阅读和搜索获授权的工作区。降权和移除立即应用到后续请求。工作区创建者保留写入权限。已有成员配置保留，新增成员的通用运行时权限关闭。

账号与成员管理请求使用浏览器会话。部署层建议使用独立的 `deploy` 人工账户（sudo），运行时使用 nologin 的 `librarian`/`caddy` 账户，root 只保留控制台 break-glass。写入时同源校验仍然生效。CLI 投递和 GitHub 备份继续使用各自的服务凭证。账号页面不会显示密码、令牌、GitHub SSH 密钥或部署密钥。 [CLI 投递](delivery.md) · [Git 备份](git-backup.md)

账号登录和自主验证旧密码共用按账号计数和实例级密码校验并发上限。短时并发登录可进入有上限的等待队列。服务直连时还按来源 IP 限流。反代部署中，仅在后端监听回环且可信代理覆写 `X-Real-IP` 时启用 `LIBRARIAN_TRUST_LOOPBACK_PROXY=1`。 [内网反代配置](lan-pre-release.md)

## 2.1 多文件事务与恢复

- 故障测试最初缺少事务接缝。接入后，真实路由在两次文件替换之间等待，第二笔失败并回滚后读回原文。故意损坏恢复材料时，最初真实路由返回了 200，修复后在恢复前返回 503。
- 两个独立子进程中断点分别位于 Git 发布前和索引安装前。前者在重开后恢复两份原件，以相同 ID 重试后才发布。后者在重开后返回相同 Git 提交并补齐暂存区，无新增版本。两条路径均核对 BOM、CRLF、尾随空白及 Git blob。
- 事务包含两份文件时，发布前旧 SHA-256 分别为 `f20fa335bf2ea137b62c113488d4792e131ff93fdbe8fa25a200fadd42256e8e` 和 `7fa7e378f50c1991c48328994aaaf2cb4bc0bd93fff2b619986d6b14c7d5227b`。发布版本对应 `189cd6436578af4e00e402ab186d0f2c1cf81188eb8e6bb8c66890cf369843f9` 和 `039c14d9a8ae2880fd523d73ef05f092c04c72657097365b73c2f4c344f27ac2`。Git trailer 携带 `Librarian-Operation-Id`。
- 审查后补测 Git 子进程在服务退出后继续执行的情况。重启在 Git 分支锁下撤销该次发布授权，随后放行旧进程。旧进程发布失败，分支仍指向原提交。同一操作随后可重新提交。临时 Git 索引丢失的另一项测试确认可从提交树重建索引并保留其他暂存文件。
- 外部文件修改仍保留，发生冲突的操作保留恢复材料。Reader 查询与索引读原文共用空间锁，搜索摘要仅在其内容版本与标题投影一致时返回。手动历史恢复复用此事务。
- 七项事务测试使用真实临时文件、SQLite、原生 Space 和 Git。执行 `cargo test --locked -p silverbullet-server --lib product::mutations::tests`。恢复证据覆盖进程退出，文件系统掉电恢复未纳入本次验证。

## 2.2 AI 操作、实际引用与 MCP

- 六项 HTTP 集成测试先因缺少操作路由返回 404。实现后，只读账户可以发起问答，无新增 Git 版本。写入两份文件会产生一个立即可读的操作版本，重复结果返回同一回执。撤销向前生成反向提交，基线已被人工移动后撤销返回 409。
- 读取内容由服务端核对当前账户与该次任务所属空间。返回的引用来自同一租约实际取得的文件。请求伪造引用返回 422，在其他空间的来源返回 404。读取后有人工保存时，执行结果返回 409 并保留人工字节。
- 删除进入待确认状态，正文保持原件。另一账号不能确认。所有者确认时重新校验基线，随后落盘并提交。
- 产品 MCP 在真实回环 OAuth 下验证了 11 个工具、稳定产品 ID、跨授权隔离、即时权限降级、刷新取令牌及撤销。四个写工具生成即时 Git 版本，重复操作返回同一回执。已有 grant 在成员降为只读后保留读取，写入会被拒绝。
- `cargo test --locked -p librarian` 通过 37 项集成测试。产品、Rust 服务与 MCP 的严格 Clippy 和格式检查通过。OpenAPI 生成及漂移检查通过。

## 2.3 独立执行器与 Reader

- 新增的事件续传、迟到租约和操作 Diff 测试最初因路由未注册得到 404。接入后，完全相同的执行器事件返回同一序号，带相同序号的不同事件返回 409。带 `Last-Event-ID` 的读取只返回遗漏事件。过期租约不能提交或续租，重新领取后也无法使用旧租约的引用 ID。
- 只读并重新领取可获得当前权限下的文件摘要。真实选区与全文有独立的来源 ID。替换正文要求执行器读取同一 revision 的完整文件。操作 Diff 读取该版本的实际 Git diff，验证了已删除的提纲路径和对未影响路径的拒绝。
- 最近操作按账号、Workspace 和文档查询。工作区级对话单独读取。终态回执和历史保留回答、引用和版本，终态记录删除完整任务提示。
- `bin/librarian/examples/ai_runner.mjs` 在独立 Node.js 进程运行。回环烟测以真实 Librarian、Git、模型接口替身和代理通过四个场景。只读问答读取正文与提纲并从暂时的模型 503 恢复。两文件写入在首次提交响应丢失后仅生成一个 Git 版本，保存后可查 Diff 和撤销。伪造来源被拒绝，旧基线写入保留较新的人工内容。模型侧使用测试凭证与本地 HTTP 替身。 [执行器配置](ai-runner.md)
- 后续补测验证新只读成员可使用真实 OAuth 同意流程创建 grant。产品 MCP 可以读取授权 Space，写入与原生 Space 转发均拒绝。上游 MCP 的 177 项测试通过。
- Reader 从文档工具条打开对话，Workspace AI 另有独立路由。1700 px 与 360 px 都能继续阅读正文。七个新增浏览器场景覆盖精确选区与语义块、独立提纲、实际引用、断开后事件续传、服务端历史重载、待确认删除、两文件 Diff 和撤销，以及服务端更新时保留本地编辑缓冲。历史工具保留原恢复提交标题。
- 最终产品套件通过 42 项 Librarian Rust 集成测试、1,357 项服务库测试（2 项忽略）、177 项 MCP 测试、43 项 Vitest 和 28 项真实产品 Playwright。严格 Clippy、Rust 格式、Reader 类型、严格 lint、格式检查、OpenAPI 和 Vite 构建通过。

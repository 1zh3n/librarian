- Max2 真机、真实软键盘、读屏、iOS/Safari 尚未验收。
- 仅用于隔离数据的内网试用；公网放行需先处理[公网安全审阅](../public-security-review.md)高优先项。
- MCP 治理、编辑器长尾、像素级视觉回归和独立 App/PWA 决策留到后续版本。
- 自动保存已增加 2 秒最长等待；编辑器 Tab 缩进等手感项不在 0.1。

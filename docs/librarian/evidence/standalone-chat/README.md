# 独立 AI 对话布局

在 `/ai` 输入两轮中文问题。第一轮比较河岸观察，含三列表格、长标识符、代码块和来源链接。第二轮选择「修改与管理」，创建「下一次外业清单.md」。两轮使用同一真实 Reader 会话，浏览器通过测试执行器提交确定性回答；鉴权、领取任务、读取来源、写入和回执均经过 Rust 产品服务。

# 阅读 A 时给 B 改名

2026-11-21，独立 Rust 产品 fixture，端口 4286。Chromium 145，桌面 1440 × 900，触屏模拟 390 × 844。改前使用 `999a4531`，改后从共享工作树复制源码独立构建。用真实账号登录，经 API 在独立空间创建 A《渡口走访手记》和 B《船工访谈》。B 的原文件名是 `资料/访谈速记.md`。

**目录焦点环修复已验证。** 修正前，按 Enter 保存后，B 行和整个目录分组各有一圈 2 px 蓝框。修正后，Enter 保存与 Esc 取消都把焦点还给 B，只在 219 × 38 px 的行上显示 2 px 实线，带焦点环的祖先数从 1 降为 0。目录分组自身获焦时仍有 2 px 焦点环。见[保存后的画面](reading-after-rename.png)和[修正前后测量](after.json)。

[改前数据](before.json)和[改后数据](after.json)含 API 状态、操作 ID、文档版本、正文摘要与视口测量。慢保存测试只延迟请求，所有读取、改名和正文保存均由 fixture 实际处理。
